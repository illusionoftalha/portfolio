# Sheikh Muhammad Talha Bin Khalid — Portfolio

> A high-performance, animation-driven personal portfolio built with vanilla HTML, CSS, and JavaScript.

🔗 **Live:** [talha-dev-topaz.vercel.app](https://talha-dev-topaz.vercel.app)

---

## Overview

A sleek developer portfolio showcasing 6+ years of WordPress and full-stack engineering work. Features a cinematic scroll experience powered by GSAP ScrollTrigger and Lenis smooth scroll, with a WebGL canvas background, custom cursor, and horizontal project gallery.

---

## Tech Stack

- **HTML5 / CSS3 / Vanilla JS** — no framework, no build step
- **GSAP + ScrollTrigger** — scroll-driven animations and pinned sections
- **Lenis** — buttery smooth scrolling
- **WebGL Canvas** — animated background that scrubs on scroll
- **Vercel** — deployment

---

## Features

- Preloader with progress counter
- Custom cursor with magnetic effect
- Film grain noise overlay
- Pinned hero section with large typographic title
- Sticky skills sequence (`WORDPRESS. PHP. JAVASCRIPT. JAVA. .NET.`)
- Horizontal scroll project gallery (6 live projects)
- Animated experience timeline (2019 → 2026)
- Text masking / reveal section with stats
- Contact form via FormSubmit with success popup
- Fully responsive

## Getting Started

No build step required. Just clone and open:

```bash
git clone https://github.com/illusionoftalha/portfolio.git
cd portfolio
# open index.html in your browser, or use a local server:
npx serve .
```

For the contact form to work, update the FormSubmit endpoint in `index.html` with your own email.
